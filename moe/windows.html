Windows

Windows 常用 Win 键

系统操作、窗口管理、截图输入与设备连接。

常用系统操作

快捷键 作用
Win打开开始菜单
Win + E打开文件资源管理器
Win + I打开设置
Win + S打开搜索
Win + R打开运行
Win + X打开高级用户菜单
Win + L锁定电脑
Win + V打开剪贴板历史

窗口管理

快捷键 作用
Win + D显示 / 恢复桌面
Win + Tab打开任务视图
Win + ↑最大化窗口
Win + ↓还原 / 最小化窗口
Win + ← / →窗口贴靠到左侧或右侧
Win + Ctrl + D新建虚拟桌面
Win + Ctrl + ← / →切换虚拟桌面
Win + Ctrl + F4关闭当前虚拟桌面

截图、输入与设备

快捷键 作用
Win + Shift + S打开截图工具
Win + PrtSc截取全屏并保存到图片文件夹
Win + .打开表情符号与符号面板
Win + H语音输入
Win + P投影 / 多屏显示模式
Win + K连接无线显示器或设备
Win + A打开快速设置
Win + N打开通知中心
