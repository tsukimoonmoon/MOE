Blender 常用快捷键

视图导航、对象操作、编辑模式、界面与显示。

视图导航

快捷键 作用
鼠标中键旋转视图
Shift + 鼠标中键平移视图
滚轮缩放视图
Numpad 1前视图
Numpad 3右视图
Numpad 7顶视图
Numpad 5透视 / 正交视图切换
Numpad 0相机视图
Home框选显示全部对象
.聚焦选中对象

对象操作

快捷键 作用
G移动
R旋转
S缩放
G / R / S + XYZ沿指定轴移动、旋转或缩放
Shift + A添加对象
X 或 Delete删除
Shift + D复制对象
Alt + D关联复制
Ctrl + A应用变换
Ctrl + Z撤销

编辑模式

快捷键 作用
Tab对象模式 / 编辑模式切换
1 / 2 / 3点 / 边 / 面选择
A全选 / 取消全选
E挤出
I内插面
Ctrl + R环切
K刀具
F填充面 / 创建边
M合并点
P分离选中部分

界面与显示

快捷键 作用
T显示 / 隐藏左侧工具栏
N显示 / 隐藏右侧属性栏
Z视图着色菜单
F3搜索命令
Ctrl + Space最大化当前区域
Space播放 / 暂停时间轴
